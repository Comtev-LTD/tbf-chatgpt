# tbf cards for ChatGPT

Start tbf group cards and look after them from ChatGPT's desktop app.

1. In ChatGPT, open Settings, Plugins, Add, Add a marketplace.
2. Paste `https://github.com/Comtev-LTD/tbf-chatgpt`.
3. Install **tbf cards** and sign in with your tbf account.
4. Type `/tbf` in a chat.
